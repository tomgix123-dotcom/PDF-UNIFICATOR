# -[ PDF UNIFICATOR ]-

### A simple PDF merger for Windows, made to be nice to use.

<img src="UNIFICADOR-DISPLAY.gif" width="700">

I made PDF UNIFICATOR because, honestly, I don't like using ugly software.

There are plenty of tools that can merge PDFs perfectly well, but some of them feel unnecessarily complicated, require command-line commands, or simply aren't very pleasant to use.

I wanted something simpler.

Select your PDFs, put them in the order you want, click merge, and you're done.

No commands. No complicated menus. No account. No internet connection required.

---

## What can it do?

* Merge multiple PDFs into a single file
* Select an entire folder of PDFs at once
* Reorder your files before merging
* Remove files you don't want
* Works on Windows
* Portable — no installation required
* Works offline — your documents stay on your computer
* A custom interface designed with usability in mind

The goal isn't to make the most complicated PDF application ever made.

The goal is to make **merging PDFs feel easy**.

---

## Download

You don't need Python or any other software to use PDF UNIFICATOR.

Download the latest `.exe` from the **Releases** section, open it, select your PDFs and start merging.

It's portable, so there is no installation process.

Just keep the `.exe` somewhere convenient and run it when you need it.

---

## How to use it

### 1. Select your PDFs

Choose individual PDF files or select a folder containing the documents you want to merge.

### 2. Arrange them

The order of the files is the order they will appear in the final PDF.

Use the up and down buttons to arrange them however you want.

### 3. Remove anything you don't need

Selected the wrong file?

Just remove it from the list.

### 4. Merge

Click **Merge**, choose where you want to save the new PDF, and you're done.

That's basically it.

---

## Your files stay on your computer

PDF UNIFICATOR works locally.

Your PDFs aren't uploaded to a website or sent to an online service just to merge them.

This also means you can use it without an internet connection.

## Portable

One of the things I wanted from the beginning was for this to be something you can just **download and use**.

No installer is required.

No Python installation is required.

No dependencies need to be installed manually.

Download the executable and run it.

## Built with

PDF UNIFICATOR is written in Python and currently uses:

* Python
* Tkinter for the interface
* pypdf for PDF processing

The application is packaged as a standalone Windows executable.

---

## Running from source

If you're interested in the code or want to run the project yourself:

```bash
pip install pypdf
```

Then:

```bash
python main_Unificador.py
```
